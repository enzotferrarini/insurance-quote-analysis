# Synthetic generation assumptions

The generator is a teaching model, not a calibrated simulation. It uses Python's local `random.Random(seed)` instance (default 42), never wall-clock time, and serializes keys in stable order. Use the same supported Python version for byte-for-byte reproducibility. The committed manifest records seed, parameters, version, counts and SHA-256 of the immutable raw JSON.

- Default population: 100 prospects. Every tenth prospect is deliberately unquoted, producing exactly 10 unquoted and 90 quoted prospects. Labels and `example.invalid` addresses are invented; no client records are copied.
- Six invented carriers: Fictional Alder, Birch, Cedar, Elm, Maple and Willow. A prospect receives distinct randomly sampled carriers. There is no carrier effect in prices or statuses.
- Prospect creation dates are uniformly sampled from the defined 12-month window, leaving enough room for quotes to be created 1–7 days later before the snapshot. Effective dates are seven days after quote creation; quote expiration is 30 days after effective date. These are simplified quote-validity assumptions, not policy terms.
- Each quoted prospect has a single product, drawn with Auto/Home/Umbrella weights 55/30/15. This is not observed market mix. Other than the designated comparison set, quoted prospects receive 2–5 quotes uniformly.
- Quoted prospects whose ID modulo 5 is 1 receive exactly four quotes. The first three have matching recorded coverage, dates and terms; the fourth has a different configuration. With the default population there are 20 such groups and 60 equivalent quotes. Other generated quote configurations intentionally differ. Analysis derives equivalence from recorded fields, not from the prospect ID rule.
- Product baseline annual premiums are $1,800 Auto, $2,600 Home and $500 Umbrella. A prospect multiplier is uniform 0.7–1.3; independent per-quote variation is uniform 0.8–1.2. Integer cents are obtained by truncation at each multiplication. Different configurations do not receive a modeled coverage-price effect; simulated ranges are not estimates of market prices or potential savings.
- Each quoted prospect has a 45% chance of one randomly selected quote being marked Accepted. Other status draws use Pending/Presented/Declined/Expired weights 15/45/25/15. Expired is replaced with Presented if the quote expiration is after snapshot. As a result, unconditional status proportions do not equal those weights. Status draws do not model event history or actual funnel behavior.
- Prospect status is New when unquoted, Accepted when a quote is accepted, otherwise Quoted. Analytics derives accepted prospects from quote status, not this redundant label. At most one quote per prospect is accepted in the generator; the fixture deliberately has two accepted quotes for one prospect to test distinct counting.
- Coverage IDs, limits, deductibles and notes are simplified invented configurations. NULL and zero have distinct meanings. No actual exclusions, endorsements, underwriting or fees are represented. Matching recorded fields is only a controlled demonstration of the comparison algorithm.

Raw JSON is immutable: an identical generator rerun reuses it; different content at the same path fails. The pipeline creates databases exclusively and refuses all existing database files. Use a new `--output` directory to regenerate or scale. Invalid examples exist only in `tests/fixtures/invalid_cases.json`, never mixed into the demo.
